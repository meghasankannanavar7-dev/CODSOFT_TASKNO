# Student Registration System

## 📌 Project Description

The **Student Registration System** is a web-based application developed to simplify the process of registering student details. It provides a simple and user-friendly interface where users can enter and submit student information.

## 🎯 Objectives

* To provide an easy student registration process.
* To collect and manage student information.
* To create a simple and user-friendly interface.
* To reduce manual registration work.
* To demonstrate web development skills using HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and user interface
* **JavaScript** – Form functionality and validation
* **VS Code** – Development environment
* **GitHub** – Project hosting and version control

## ✨ Features

* Student registration form
* Student details input
* Form validation
* User-friendly interface
* Responsive design
* Submit and reset functionality
* Clean and simple layout

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The Student Registration website will open in your browser.
